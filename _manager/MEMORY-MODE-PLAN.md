## 3. Поділ за віком

### Звідки беруться межі

Не з круглих чисел, а з двох задокументованих порогів розвитку (розділ 3 дослідження):
- **8 років** — до нього utilization deficiency: дитина виконує техніку правильно, а результат ще не росте
- **10 років** — раніше палац пам'яті не працює, потрібна абстрактна просторова структура

✅ **Обрано User — межі за доказами (5–7 / 8–9), розбіжність з курсовими групами прийнято свідомо.**

| Група | Вік | Що визначає межу |
|-------|-----|------------------|
| 1 | **5–7** | До порогу 8. 🔴 Прогрес рахуємо за виконанням техніки, НЕ за результатом пригадування |
| 2 | **8–9** | Стратегії вже дають результат («все або нічого»), але палац ще ні |
| 3 | **10–12** | Палац пам'яті стає доступним — відкривається головна техніка |
| 4 | **13–17** | Повний набір. Тригери й приклади — підліткові (дедлайни, форма, відповісти) |
| 5 | **18+** | Повний набір + implementation intentions без спрощень |

⚠️ **Розбіжність з курсовими групами, яку треба свідомо прийняти:** у курсах групи 5-6 / 7-9 / 10-12. Тут поріг 8 розрізає «7-9» навпіл — 7-річний і 9-річний потребують **різного способу рахувати прогрес**. Тому 5–7 / 8–9, а не 5-6 / 7-9. Якщо для вас важливіша єдність з курсами — можна лишити 7-9 однією групою, але тоді всередині неї прогрес для 7-річних все одно доведеться рахувати окремо, тобто складність не зникне, а сховається.

**Старших дорослих окремою групою НЕ виділяємо.** Доказово їм потрібна та сама мнемотехніка плюс більше психоедукації — а окрема кнопка «60+» читається як образа. Замість неї: 18+ одна група, а текст екрана «Чому ти забуваєш» тихо адаптується за віком з профілю.

### Як обирається група

`calcAge(profile.birthdate)` **вже існує** (state.js:375, з FB-44) — вік у застосунку є.

1. Є дата народження → група підбирається автоматично
2. Немає → одноразове питання при першому вході в режим
3. **Завжди можна змінити вручну** — батько налаштовує дитині, бабуся онуку, доросла людина хоче простіший рівень

Зберігати окремо від `profile.birthdate` (напр. `memori_memory_group`), бо це вибір режиму, а не факт про людину.

### MT-02 · E-04 «Якщо-то» — головна вправа режиму

```
ID: MT-02 / E-04
Механізм: implementation intentions (проспективна пам'ять)
Рівень доказу: 🟢 Сильний
Джерело: PLOS One 2021; огляд PM у дитинстві, Psychological Research 2023
Вік: усі, тригер змінюється — 5-9 фізичний, 10+ будь-який

Побутовий біль: дитина «забув здати зошит», підліток «забув про дедлайн»,
                дорослий «забув що купити», старший «забув таблетку»
Перевірка Правила №2: ✅ це і є проспективна пам'ять напряму

Хід вправи:
  1. Користувач обирає намір зі списку або пише свій
     («передзвонити мамі», «взяти форму»)
  2. Застосунок веде до формули: «ЯКЩО [тригер], ТО [дія]»
     — 5-9: тригер тільки з готового списку фізичних подій
       (відкрию пенал / сяду вечеряти / взую кросівки)
     — 10+: можна свій, підказка «має бути щось, що точно помітиш»
  3. Проговорити/набрати повну фразу — це і є кодування
  4. Увечері push: «Спрацювало?» → Так / Ні / Ще не було тригера
Тривалість: 2 хв на створення, перевірка ввечері
Відкладена перевірка: так, того ж дня ввечері; повторне кодування наступного
  дня, якщо «Ні» — одноразового формулювання доказово мало

🔴 Тон на «Ні»: без докору. «Буває. Спробуємо той самий намір із
   помітнішим тригером?» — і запропонувати змінити тригер, не дію.

Дані: memori_memory_intentions [{id, text, trigger, createdAt, checkedAt, result}]
Що НЕ робимо: не перетворюємо на список справ / нагадувалку.
  Ми тренуємо формулу, а не ведемо задачі. Максимум 3 активні наміри.
```

### MT-03 · E-02 Ланцюжок-історія

```
ID: MT-03 / E-02
Механізм: story / chain method (мнемотехніка)
Рівень доказу: 🟢 Сильний
Вік: 5-7 спрощено (5 слів + картинки), 8+ повна (10 слів)

Хід вправи:
  1. Показуємо 10 слів по одному (5-7: 5 слів, з картинкою)
  2. Просимо зв'язати кожне наступне з попереднім в одну абсурдну історію
     — приклад-зразок показуємо ЩОРАЗУ (production deficiency:
       дитина не згадає прийом сама, навіть якщо вміє)
  3. Відтворити по порядку
  4. Відкладена перевірка через 20 хв або наступного дня (push)
Тривалість: 4-5 хв

🔴 5-7 років: показуємо, скільки слів згадав, БЕЗ бала й серії
   (utilization deficiency). Прогрес-мітка: «історію склав» ✅,
   а не «згадав 7 з 10».

Дані: memori_memory_chain [{setId, words[], recalledAt, delayedRecall}]
Що НЕ робимо: не беремо слова з Words Mode — це тренування пам'яті,
  а не вивчення лексики. Слова навмисно нейтральні й непов'язані.
```

### MT-08 · E-11 Повторення + інтерактивні образи (5–9)

```
ID: MT-08 / E-11
Механізм: cumulative rehearsal + interactive imagery
Рівень доказу: 🟡 Добрий, віковий (тренувались саме на 5-9 роках)
Джерело: PMC4416471
Вік: 5-9 — це ядро для найменших, блокер дитячого режиму

Хід вправи (інтерактивні образи):
  1. Дві картинки поруч (ложка, слон)
  2. «Придумай, що вони РАЗОМ роблять» — слон їсть ложкою
     (взаємодія, не просто сусідство — у цьому весь ефект)
  3. Пізніше показуємо одну → просимо згадати другу

Хід вправи (кумулятивне повторення):
  1. Слово → повтори
  2. Нове слово → повтори ОБИДВА
  3. Нове → повтори всі три ... до 5

🔴 Прогрес рахуємо за виконанням: «придумав зв'язку» / «повторив усі».
   НЕ за кількістю згаданого. Жодних балів, серій, відсотків.
   Причина — utilization deficiency: дитина робить усе правильно,
   а результат ще не росте, і бал покаже їй провал, якого немає.

Дані: memori_memory_kids {exercisesDone, lastAt} — навмисно без метрик якості
Що НЕ робимо: не показуємо дитині порівняння з іншими, з нормою,
  зі своїм минулим результатом.
```

**Далі за пріоритетом:** MT-01 (E-03 відкладене пригадування — найдешевше, нотифікації вже є), MT-04 (E-10 екран психоедукації, це просто текст ×6 мов ×вік), MT-05 (E-01 палац пам'яті — найсильніший доказ, найдорожчий UI).
